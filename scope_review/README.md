# YARA 规则 condition 离线保守比较（scope_diff）

复审规则组时，不能只看 condition 的文字 diff：纯布尔调序会改文字但不改
检测范围，而真正的扩围也可能只改几个字。本工具用 plyara 解析规则后，
对 condition 做**离线、保守**的语义比较，直接给出定级结论和判定依据。

## 判定结论

| 结论   | 含义                                   | 复审动作       |
|--------|----------------------------------------|----------------|
| 等价   | 两版 condition 布尔等价（含纯调序）    | 无需升档       |
| 扩围   | 新版命中文集严格变大                   | **需要升档复审** |
| 缩围   | 新版命中文集严格变小                   | 无需升档       |
| 不可比 | 互有增删，两个方向都不蕴含             | 需人工复核     |
| 未知   | 含库调用 / 动态计数等不支持构造        | 需人工复核     |

文件级另有「新增规则」「删除规则」两种提示。

## 支持范围

- 支持：\`and\` / \`or\` / \`not\` / 括号 / \`true\` / \`false\` / 固定字符串引用（\`$a\`）。
- 不支持（一律判「未知」，留待人工）：库函数调用（\`pe.imports(...)\` 等）、
  动态计数（\`#a > 2\`、\`@a\`、\`!a\`）、\`of\` / \`for\` 表达式、\`uint*\`、
  \`filesize\`、算术与比较运算、\`$a[i]\` / \`$a*\` 等。

## 判定方法（为什么保守安全）

1. 每个字符串引用按**字符串定义**（类型 + 值 + 修饰符）抽象成独立布尔原子，
   而不是按名字：改名不改定义视为同一原子；同名但定义被改视为不同原子。
2. 在两版原子的并集上枚举真值表（上限 16 个原子，超出判「未知」）：
   - 全部赋值一致 → 等价
   - 旧=>新恒成立且有新真旧假的赋值 → 扩围（附新增命中的赋值示例）
   - 新=>旧恒成立且有旧真新假的赋值 → 缩围（附被移除命中的赋值示例）
   - 两个方向都有反例 → 不可比（附两个方向的反例赋值）
3. 保守性：全集赋值上成立的蕴含，在原子取值存在任何相关性时仍然成立，
   因此「等价 / 扩围 / 缩围」的结论不会误报；可能漏掉依赖字符串内容
   相关性的蕴含（如一个字符串是另一个的子串），此时会保守地落入
   「不可比」而不是误判方向。

## 用法

\`\`\`sh
python3 scope_review/scope_diff.py OLD.yar NEW.yar          # 文本报告
python3 scope_review/scope_diff.py OLD.yar NEW.yar --json   # JSON 报告
\`\`\`

按规则名自动配对两版文件中的规则。退出码：全部无需关注为 0；
存在扩围 / 不可比 / 未知 / 新增规则时为 1，便于接入复审流水线。

## 示例

\`scope_review/rules/\` 下有三对最小示例：

- \`case1_reorder_*.yar\`：纯布尔重排 → 等价
- \`case2_mutual_*.yar\`：互有增删（\`$b\` 换成 \`$c\`）→ 不可比
- \`case3_libcall_*.yar\`：\`pe.imports\` 库调用 → 未知

运行：

\`\`\`sh
python3 scope_review/scope_diff.py scope_review/rules/case1_reorder_old.yar scope_review/rules/case1_reorder_new.yar
\`\`\`
