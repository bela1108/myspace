# DUO139

This linter tracks internal data-export generators that emit their rows one at
a time and rely on in-house `audit_start`/`audit_end` bookkeeping. A generator
that is created but never consumed never runs any of its body, so its ending
audit is never confirmed.

## Problematic code

```python
def export_rows():
    audit_start()
    yield 1
    yield 2
    audit_end()


def hold():
    gen = export_rows()
    return gen
```

## Correct code

Consume the generator, or place the ending audit in a `finally` block so it is
confirmed regardless of how consumption stops.

```python
def export_rows():
    try:
        audit_start()
        yield 1
        yield 2
    finally:
        audit_end()
```

## Rationale

Handing a generator to a downstream consumer does not guarantee that the code
written after the final `yield` ever runs. An ending audit that is only reached
on full exhaustion can be silently skipped.

## Exceptions

None
