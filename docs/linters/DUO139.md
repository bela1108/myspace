# DUO139

This linter checks the "internal review" decorator convention used by the
export review process. The export review only looks at decorator *names*, so
a same-named impostor or a marker carrying the wrong review policy passes
undetected. This linter instead traces each decorator through the AST to the
review policy identity it evaluates to, and requires the effective policy to
be `"internal"`.

The analysis is order-sensitive: a rebinding that happens after a function
definition does not retroactively change that function's attribution. It
supports module aliases, definitions nested in class bodies, and local
factories through a limited return summary (a function whose body is a
single `return <known factory>(...)` statement). When stacked markers
disagree, the topmost (last applied) marker wins and the diagnostic
explains the ordering.

This is **not a security bug**, but is a common way to accidentally bypass
the internal review process.

## Problematic code

```python
import review

@review.policy("public")
def func():
    pass
```

```python
from review import internal_review

def internal_review(func):  # shadows the import from this point on
    return func

@internal_review
def func():
    pass
```

```python
import review

@review.policy("public")   # applied last, overrides the marker below
@review.policy("internal")
def func():
    pass
```

## Correct code

```python
import review

@review.internal_review
def func():
    pass
```

```python
import review

@review.policy("internal")
def func():
    pass
```

## Rationale

A name-only export review cannot tell `review.internal_review` apart from a
local function that happens to share its name, nor can it evaluate marker
factories. Tracing the decorator to its definition site and evaluating the
policy identity it carries closes that gap.

## Exceptions

The return summary for local factories is intentionally limited: only a
single `return <known factory>(...)` statement with string-literal
arguments is summarized. Decorators that cannot be tied to the review
convention at all (e.g. ordinary logging decorators) never produce a
diagnostic.
