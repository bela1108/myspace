# DUO139

This linter searches for desensitization jobs registered with the in-house
queue scheduling API (`scheduler.defer` / `scheduler.enqueue`) whose data
level is selected through a captured variable. Python closures are
late-binding: a deferred callback reads the variable when the queue drains,
not when the job is registered. Static review of the registration site can
therefore conclude the data level is fixed when it is not.

Three capture patterns are modeled separately:

* **Closure reads**: the callback reads a free variable that is rebound in
  the enclosing queue batch (a loop target, an assignment inside the loop
  body, or an assignment after the registration call). The diagnostic
  reports the desensitization call-site location and the level the variable
  provably resolves to when the queue drains.
* **Default-value captures**: the variable is bound as a parameter default
  (e.g. `lambda level=level: ...`). This evaluates at registration time and
  is safe.
* **`nonlocal` reassignments**: a sibling callback declares the variable
  `nonlocal` and reassigns it, mutating the shared binding between
  registration and execution.

Only source is examined. A deferred callable produced by an unknown
higher-order wrapper cannot be resolved statically and is reported for
manual review. Each enclosing loop forms an independent queue batch, so
capture results from separate batches are never merged.

## Problematic code

```python
import scheduler
import desensitize

def run_cleanup(batches):
    for batch in batches:
        level = "internal"
        # the deferred callback reads "level" when the queue drains,
        # not the value seen here at registration time
        scheduler.defer(lambda: desensitize.apply(batch, level=level))
```

```python
import scheduler
import desensitize

def run_cleanup(records):
    level = "public"

    def escalate():
        nonlocal level
        level = "secret"

    scheduler.defer(escalate)
    scheduler.defer(lambda: desensitize.apply(records, level=level))
```

## Correct code

Bind the level at registration time with a default-value capture, or use a
literal:

```python
import scheduler
import desensitize

def run_cleanup(batches):
    for batch in batches:
        level = "internal"
        scheduler.defer(lambda level=level: desensitize.apply(batch, level=level))
```

```python
import scheduler
import desensitize

def run_cleanup(batch):
    scheduler.defer(lambda: desensitize.apply(batch, level="public"))
```

## Rationale

Desensitization applies a data level to protect sensitive information. If
the level is selected through a late-binding closure, every job registered
in the same batch observes the variable's final value when the queue
drains. Jobs reviewed as handling low-sensitivity data may run with a
different level than intended, or a level intended for one batch may leak
into another.

## Exceptions

* A deferred callable returned by an unknown higher-order wrapper cannot
  be resolved from source alone. The linter reports these for manual
  review instead of guessing.
* Levels selected through expressions other than plain names (e.g.
  attribute access or helper calls) are outside this rule's capture model.
